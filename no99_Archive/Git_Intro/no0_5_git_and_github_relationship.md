# Git 與 GitHub 的關係

- 初學者常混淆兩者
- 本文件釐清定義與關係

---

## 核心定義

- Git
    - 分散式版本控制系統
    - 軟體工具
    - 安裝於開發者的電腦
    - 追蹤檔案變更
    - 管理歷史版本
    - 處理分支與合併
- GitHub
    - 雲端託管服務平台
    - 基於 Git 建置
    - 網站服務
    - 託管遠端儲存庫
    - 圍繞 Git 建立協作工具

---

## 關係比喻：工具與平台

- 情境設定
    - 世界上只有 Git
    - 開發者於本機執行版本控制
    - 版控歷史只存在本機電腦
    - 缺乏跨電腦共用的管道
    - 缺乏跨團隊共用的管道
- GitHub 的角色
    - 提供雲端中央儲存庫
    - 開發者可推送本機歷史紀錄
    - 紀錄同步至中央儲存庫
- 帶來的改變
    - 跨裝置工作
        - 開發者於公司 push 進度
        - 返家後 pull 最新進度
        - 接續原本工作
    - 團隊協作
        - 其他開發者 pull 進度
        - 修改後再 push 回去
        - 多人協作同一專案

---

## 功能對比

| 特性 | Git 工具 | GitHub 平台 |
| :--- | :--- | :--- |
| 主要功能 | 版本控制、歷史追蹤、分支合併 | 程式碼託管、協作、專案管理 |
| 運作地點 | 本機電腦，離線 | 雲端伺服器，連線 |
| 核心價值 | 追蹤程式碼的內容與歷史 | 提供圍繞程式碼的社交流程 |
| 代表功能 | `commit`、`branch`、`merge` | Pull Request、Issues、Actions、Wiki |

---

## 結論

- Git 與 GitHub 可分開使用
    - 開發者可只使用 Git
    - 不使用 GitHub 也可以
    - 僅在本機進行版本控制
- GitHub 依賴 Git 而存在
    - 沒有 Git 就沒有 GitHub
    - 功能建立於 Git 之上
- GitHub 是託管服務之一
    - 其他知名平台
        - GitLab
        - Bitbucket
