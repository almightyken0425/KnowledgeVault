# Git 下載與安裝

- 開發者需先安裝 Git。
- 安裝後才能開始使用 Git。

## 官方下載來源

- 官方網站是 Git 的下載來源。
- 此來源最可靠。
- 官方網站網址為 https://git-scm.com/
- 官方網站自動偵測作業系統。
- 支援平台：
    - Windows
    - macOS
    - Linux
- 網站依偵測結果提供下載連結。
- git-scm.com 由 Git 社群維護。
- git-scm.com 非由單一企業直接擁有或營運。
- Microsoft 為此類企業的範例之一。
- Microsoft 是 Git 生態系的重要貢獻者。
- 官方網站維持獨立性。
- 此獨立性確保官方網站中立。

---

## 下載取得的內容

- 開發者從官網下載並安裝 Git。
- 下載可取得 Git 核心命令列工具。
- 此工具英文稱為 Core Command-Line Tool。
- 此工具可在終端機中執行。
- 終端機英文稱為 Terminal。
- 此工具也可在 Command Prompt 中執行。
- Git 所有功能皆源自此核心工具。
- 功能複雜度不影響此關聯。
- 後續筆記皆圍繞此核心工具展開。
