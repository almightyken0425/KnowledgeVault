# Git 是程式碼版本控制系統

## Git 的定義與比喻

- Git 是一套版本控制系統
- 英文全稱為 Version Control System
- 縮寫為 VCS
- 比喻:
  - 遊戲存檔點:
    - 開發者完成一個階段性工作
    - 隨即可以存檔
    - 此存檔動作稱為 `commit`
    - 事後發生錯誤
    - 可讀取先前的存檔點
    - 讀取後專案回到當時狀態
  - 程式碼時光機:
    - 記錄專案每個檔案
    - 記錄檔案的所有修改歷史
    - 開發者可查看任一時間點的修改
      - 例如昨天下午三點的修改
    - 開發者可比較任兩版本的差異
      - 例如上週與現在的版本

---

## 版本控制的必要性

- 缺乏版本控制時的檔案管理方式:
  - `專案_final.zip`
  - `專案_final_v2.zip`
  - `專案_final_真的最終版.zip`
  - `專案_final_打死不改版.zip`
- 這種方式的缺點:
  - 容易混亂
  - 容易出錯
  - 難以與其他開發者協作
- Git 的核心目的:
  - **追蹤變更:**
    - 清晰記錄每一次修改
    - 記錄修改者是誰
    - 記錄修改時間
    - 記錄修改了什麼內容
  - **團隊協作:**
    - 多位開發者可同時工作
    - 開發者可在同一專案協作
    - 避免開發者之間互相覆蓋程式碼
  - **平行開發:**
    - 讓開發者開闢新的開發分支
    - 開發者可在分支上嘗試新功能
    - 新功能不影響穩定的主線版本
