# 工作日曆定案紀錄

> 本篇記錄 IGotThis 工作日曆的定案。內容含天數單位、日曆定義的歸屬與選用規則、日曆的內容形態。由工單資料模型定案所列的範圍外依賴推導而來，每項定案附選擇理由。

## 本篇範圍

- **涵蓋:**
    - 天數單位的定義
    - 日曆定義的歸屬
    - 日曆的選用規則
    - 日曆的內容形態
- **不涵蓋:**
    - 個人請假與假勤管理
    - 跨時區的時間顯示
    - 加班與工時上限
- **推導前提:**
    - 起訖日為日期型別，不含時間部分
    - 偏離天數直接顯示，不設嚴重程度門檻

---

## 天數單位定案

- 時間軸走日曆天，天數統計走工作天
- 甘特圖橫軸依日曆排列，假日格以灰底標示
- 長條跨越假日照常繪製，不切斷
- 工期數字扣除假日
- 偏離天數扣除假日
- DueDate 維持日曆天，對外承諾不因假日改變

```
        3/1              3/20        4/15
母單    ████████████████
子單    ███████████████████████████████
             ▓▓▓▓ 假日
        偏離 十六個工作天
```

- **選擇理由:**
    - 一律日曆天 → 長假期間的偏離數字全部虛胖
    - 一律工作天 → 橫軸跳過假日 → 時間軸無法對照真實日期
    - 兩種單位並存的代價是標示成本，換到兩邊都準確
- **標示要求:**
    - 顯示天數之處須標明單位
    - 未標單位的數字會被誤讀

---

## 日曆定義的歸屬

- 日曆定義收在 Company 定義區
- 定義區可收多份日曆
- 一份日曆對應一個地區的行事曆
- 日曆定義的編輯權歸型別維護開關
- **不另開權限開關的理由:**
    - 日曆同為公司層的共用定義
    - 改錯假日 → 全公司天數跑掉
    - 殺傷力與改錯欄位定義同級
- **不綁組織層級的理由:**
    - 一個 `Team` 可能跨國家
    - 團隊成員分散各地 → 該團隊走哪國行事曆答不出來
    - 綁 `Product` 或 `Mgmt` 同樣答不出來

---

## 日曆的選用

- 帳號設一份預設日曆
- 檢視層各自選用日曆，未選用則跟隨帳號預設
- 工單詳情頁的天數依帳號預設日曆計算

```
帳號                          Company 定義區
├── Name                      ├── 日曆 台灣
├── Role 清單                 ├── 日曆 日本
├── 預設日曆                  └── 日曆 越南
└── 標籤
```

- **選擇理由:**
    - 一個帳號對應一名成員 → 一名成員在一個地區
    - 帳號是能回答走哪份行事曆的最小單位
- **同一數字因人而異可接受:**
    - 資料完整，未被隱藏
    - 差異來自尺規不同，非資訊缺失
    - 攝氏與華氏描述的是同一個溫度
    - 權限粒度定案禁止的是資訊缺失造成的數字歧異
- 顯示天數之處須一併標明所用日曆

---

## 日曆只影響派生值

- 日曆影響算出來的數字，不影響存進去的值
- 起訖日一律由使用者填寫
- 系統不提供填入工期自動推算結束日
- **選擇理由:**
    - 自動推算會讓不同日曆算出不同結束日
    - 結束日是儲存值 → 儲存值不得因檢視者而異
    - 日曆維持只讀不寫 → 資料保有單一真相

---

## 日曆的內容形態

- 一份日曆由週規則與例外清單組成
- 週規則記每週固定休息的星期
- 例外清單記逐日的覆寫
- **例外為雙向覆寫:**
    - 工作日改為假日，用於國定假日
    - 假日改為工作日，用於調整放假後的補班日
- 個人請假不進日曆
- **不納入個人請假的理由:**
    - 系統無請假功能
    - 個人假期屬人事系統的資料
    - 納入後每名成員各有一份日曆 → 天數計算失去共同基準

## 日曆的儲存形態

```sql
CREATE TABLE calendar_def (
  name       text PRIMARY KEY,
  weekly_off int[]
);

CREATE TABLE calendar_exception (
  calendar_name text,
  the_date      date,
  is_working    boolean,
  PRIMARY KEY (calendar_name, the_date)
);
```

- `weekly_off` 記每週固定休息的星期代碼
- `is_working` 為真表示該日由假日改為工作日
- `is_working` 為假表示該日由工作日改為假日
- 帳號的預設日曆與檢視層的選用日曆各存一個日曆名稱
- 未設定日曆時退回日曆天計算

## 定案對範圍外工作的依賴

- 本篇範圍內的項目皆已定案
- **個人請假未設計:**
    - 成員的實際可用天數無法反映在工期
- **跨時區顯示未處理:**
    - 起訖日無時間部分，不受時區影響
    - 建立時間與更新時間為時間戳，顯示時區未定
